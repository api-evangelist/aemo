# AEMO — Australian Energy Market Operator

> AEMO is the independent system and market operator for Australia's electricity and gas systems. It runs the National Electricity Market (NEM), the Wholesale Electricity Market (WEM) in Western Australia, the gas markets and Gas Bulletin Boards, the DER Register, and is the Consumer Data Right secondary data holder for energy. Its participant APIs run on an Azure API Management e-Hub at dev.aemo.com.au; most require formal participant onboarding, an APIM subscription key, an AEMO-signed TLS client certificate and a URM or OAuth 2.0 identity. A small number of public data feeds are anonymous.

## Notes for agents

- Almost every AEMO API is restricted to authorised market participants. Browsing docs is anonymous; calling is not.
- There is no idempotency key anywhere in the AEMO estate. Never blind-retry a submission — read back with the corresponding get operation first.
- HTTP 422 usually means the URM user lacks the required permission, not that the payload is wrong.
- HTTP 429 is throttling with no published quota and no Retry-After header. Back off exponentially.
- Bidding, balancing submissions, outage lodgement and DER Register writes change regulated market state. Treat them as human-in-the-loop.
